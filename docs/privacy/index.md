# 개인정보처리방침

시행일: 2026년 10월 9일

Zalo 다국어 번역기(이하 “확장프로그램”)는 번역 기능을 제공하는 데 필요한
최소한의 정보만 처리합니다.

## 처리하는 정보와 목적

- 사용자가 확장프로그램의 입력란에 작성하고 번역을 요청한 문장을 사용자가 선택한
  한국어·영어·베트남어 중 다른 언어로 번역하기 위해 처리합니다.
- 사용자가 받은 메시지의 번역 버튼을 누르거나 자동 번역을 켠 경우, 해당 메시지를
  사용자의 기본 언어로 번역하기 위해 처리합니다. 자동 번역은 기능을 켠 이후 새로
  도착했고 기본 언어와 다른 것으로 판별된 메시지에만 적용됩니다.
- 확장프로그램 사용 여부, 기본 언어, 사용자가 선택한 성별, 보내는 언어, 말투,
  베트남어 호칭, 자동 번역 설정, 패널 위치, 날짜별 번역 횟수·원문 문자 수·오류 횟수를
  브라우저의 로컬 저장소에 저장합니다. 성별은 관계별 호칭을 자연스럽게 번역하는
  목적으로만 사용합니다.
- 사용자가 대화별 언어를 직접 지정하면 원래 대화방 식별자를 저장하지 않고 기기 안에서
  생성한 비식별 해시 키와 선택 언어·말투·관계·상대적 나이·성별 설정만 브라우저의
  로컬 저장소에 저장합니다. 호칭이 필요한 번역 요청에는 이름이나 대화방 식별자 없이
  사용자가 선택한 관계 정보만 번역 서버로 전송될 수 있습니다.
- 서비스 운영과 장애 진단을 위해 서버 로그에 요청 식별자, 입력 문자 수, 사용 모델,
  처리 시간 및 오류 코드가 기록될 수 있습니다.
- Google Cloud 인프라의 기본 요청 로그에는 접속 IP 주소와 요청 시간 같은 네트워크
  메타데이터가 포함될 수 있습니다.

Zalo 로그인 정보, 쿠키, 비밀번호, 연락처 목록이나 대화방 목록을 수집하거나 저장하지
않습니다. 번역 원문과 번역 결과는 서버 로그나 데이터베이스에 저장하지 않습니다.

## 정보의 전송과 제3자 처리

번역을 요청하거나 받은 메시지 자동 번역을 활성화하면 번역 대상 문장이 암호화된 HTTPS
연결을 통해 운영자의 Google Cloud Run 서버로 전송되고, 번역 생성을 위해 Google
Gemini API에 전달됩니다. Google의 데이터
처리에는 [Google 개인정보처리방침](https://policies.google.com/privacy)이 적용될 수
있습니다.

확장프로그램은 정보를 판매하지 않으며, 맞춤 광고·신용 평가·사용자 추적 목적으로
사용하지 않습니다.

## 보관 기간

- 번역 원문과 결과는 요청 처리 중에만 일시적으로 사용하며 운영자가 별도로 보관하지
  않습니다.
- 브라우저에 저장된 설정과 집계 사용량은 사용자가 확장프로그램 데이터를 삭제하거나
  확장프로그램을 제거할 때까지 남을 수 있습니다.
- 원문이 포함되지 않은 Cloud Run 운영 로그와 IP 주소 등 네트워크 메타데이터는 Google
  Cloud 프로젝트에 설정된 로그 보관 정책에 따라 삭제됩니다.

## 사용자의 선택

확장프로그램 설정에서 기능을 끌 수 있습니다. Chrome 설정에서 확장프로그램 저장
데이터를 삭제하거나 확장프로그램을 제거하면 로컬 데이터가 삭제됩니다. 민감정보나
불필요한 개인정보는 번역 입력란에 작성하지 않는 것을 권장합니다.

## 보안

전송 중인 데이터는 HTTPS로 보호하며, Gemini API 키는 서버에서만 관리하고
확장프로그램에 포함하지 않습니다. 합리적인 기술적·관리적 보호조치를 적용하지만 모든
인터넷 전송의 절대적인 안전을 보장할 수는 없습니다.
