# Chrome 웹 스토어 등록 문구 (한국어)

## 제품 이름

Zalo 한국어-베트남어 번역기

## 요약 설명

Zalo Web에서 한국어를 자연스러운 베트남어로 번역하고, 확인한 뒤 전송하세요.

## 자세한 설명

Zalo Web을 사용하는 한국인을 위한 메시지 번역 도구입니다.

- Zalo 화면 안의 전용 패널에서 한국어 작성
- 첫 번째 Enter로 베트남어 번역
- 번역 미리보기 확인 및 직접 수정
- 두 번째 Enter 또는 버튼으로 현재 대화에 전송
- 자연스럽게, 정중하게, 친근하게, 동료·고객·연장자에게 등 말투 선택
- 전송 성공 후 입력란 자동 초기화
- 날짜별 번역 횟수와 문자 수를 기기 안에서 확인

사용자가 번역과 전송을 각각 명시적으로 실행해야 하며, 자동으로 대화를 읽거나
메시지를 발송하지 않습니다. 현재 버전은 한국어 입력을 베트남어로 번역합니다.

## 단일 목적 설명

Zalo Web에서 사용자가 직접 작성한 한국어 메시지를 베트남어로 번역하고, 검토 후 현재
대화 입력창으로 전송하도록 돕습니다.

## 권한 사용 사유

### storage

확장프로그램 사용 여부, 말투 설정과 날짜별 번역 횟수·문자 수·오류 수를 사용자의
브라우저에 저장하기 위해 사용합니다. 메시지 본문은 저장하지 않습니다.

### https://chat.zalo.me/*

Zalo Web에 번역 패널을 표시하고, 사용자가 명시적으로 전송을 실행했을 때 현재 활성
대화의 입력창에 확인된 번역문을 입력·전송하기 위해 필요합니다.

### https://zalo-translator-api-s6bip5vp3a-du.a.run.app/*

사용자가 번역을 요청한 한국어 문장을 운영 번역 서버로 보내고 베트남어 번역 결과를
받기 위해 필요합니다.

## 원격 코드

원격 코드를 실행하지 않습니다. 실행 코드는 확장프로그램 패키지에 포함되며, 원격
서버는 번역 API 응답만 반환합니다.

## 개인정보 공개 항목 작성 참고

- `개인 통신(Personal communications)` 또는 이에 해당하는 항목: 수집/처리에 체크
- `웹사이트 콘텐츠(Website content)` 항목이 별도로 표시되면 번역 기능 제공 목적의
  처리에 체크
- 사용 목적: 핵심 기능 제공
- 판매, 광고, 신용 평가, 무관한 목적 사용: 모두 해당 없음
- 개인정보처리방침 URL:
  `https://anchor-work.github.io/zalo-auto-translator/privacy/`

실제 대시보드 질문 문구가 다르면 정보를 적게 보이게 하는 선택이 아니라, “사용자가
입력한 메시지가 번역 서버와 Gemini로 전송된다”는 사실이 정확히 드러나는 항목을
선택합니다.

## 심사자 테스트 안내

1. `https://chat.zalo.me/`에서 Zalo 계정으로 로그인합니다.
2. 대화방을 열고 Zalo 메시지 입력창을 한 번 클릭합니다.
3. 우측 하단 번역 패널의 한국어 입력란에 문장을 입력합니다.
4. Enter를 한 번 눌러 번역 미리보기를 확인합니다.
5. Enter를 다시 누르거나 `Zalo로 전송` 버튼을 눌러 현재 대화에 전송합니다.
6. Shift+Enter는 줄바꿈이며 Esc는 번역 결과를 취소합니다.

## 스크린샷 체크리스트

실제 Zalo 계정·대화 상대·전화번호·프로필 사진은 모자이크 처리합니다. 기능을 정확히
보여 주는 실제 화면을 사용하고 합성 화면은 사용하지 않습니다.

1. Zalo Web 우측 하단에 번역 패널이 표시된 전체 화면
2. 한국어 원문과 베트남어 번역 미리보기가 함께 보이는 화면
3. 가능하면 개인정보를 가린 전송 완료 화면
