# Chrome 웹 스토어 등록 문구 (한국어)

## 제품 이름

Zalo Language Bridge

## 요약 설명

Write and understand Zalo Web messages naturally across Korean, English, and Vietnamese.

## 자세한 설명

Zalo Web에서 한국어·영어·베트남어를 사용하는 사람을 위한 메시지 번역 도구입니다.

- 처음 실행할 때 내 기본 언어와 보내는 언어 선택
- 한국어·English·Tiếng Việt 버튼으로 초기 화면 언어 즉시 전환
- 사용자 성별과 상대방 관계를 반영한 자연스러운 호칭 번역
- 선택한 기본 언어로 표시되는 팝업과 Zalo 번역 패널
- Zalo 화면 안의 전용 패널에서 메시지 작성
- 첫 번째 Enter로 선택한 언어로 번역
- 번역 미리보기 확인 및 직접 수정
- 두 번째 Enter 또는 버튼으로 현재 대화에 전송
- 자연스럽게, 정중하게, 친근하게, 동료·고객·연장자에게 등 말투 선택
- 관계에 맞는 베트남어 호칭 선택
- 한국어·영어·베트남어로 보내기 및 받은 메시지를 내 기본 언어로 번역
- 메시지별 언어 감지와 동일 언어 번역 버튼 자동 숨김
- 대화방별 언어 자동 감지 또는 직접 지정
- 대화방별 말투·호칭 설정 자동 저장과 접힌 요약 UI
- 메시지를 가리지 않도록 번역 패널 드래그 이동
- 받은 메시지별 번역 버튼과 새 메시지 자동 번역 옵션
- 전송 성공 후 입력란 자동 초기화
- 날짜별 번역 횟수와 문자 수를 기기 안에서 확인

사용자가 번역과 전송을 각각 명시적으로 실행해야 하며, 자동으로 대화를 읽거나
메시지를 발송하지 않습니다.

## 단일 목적 설명

Zalo Web에서 사용자가 직접 작성한 메시지를 한국어·영어·베트남어로 번역해 전송하고,
사용자가 선택하거나 자동 번역을 활성화한 수신 메시지를 기본 언어로 이해하도록 돕습니다.

## 권한 사용 사유

### storage

확장프로그램 사용 여부, 언어·성별·말투·호칭·자동 번역 설정, 패널 위치, 대화별 설정과 날짜별
번역 횟수·문자 수·오류 수를 사용자의 브라우저에 저장하기 위해 사용합니다. 대화별
설정은 비식별 해시 키로 저장하며 메시지 본문은 저장하지 않습니다.

### https://chat.zalo.me/*

Zalo Web에 번역 패널과 메시지별 번역 버튼을 표시하고, 사용자가 명시적으로 전송을
실행했을 때 현재 활성 대화의 입력창에 확인된 번역문을 입력·전송하기 위해 필요합니다.
받은 메시지는 번역 버튼 표시 여부를 기기 안에서 판단하고, 사용자가 번역 버튼을 누르거나
자동 번역을 켠 경우에만 번역 서버로 전송합니다.

### https://zalo-translator-api-s6bip5vp3a-du.a.run.app/*

사용자가 번역을 요청한 문장을 운영 번역 서버로 보내고 선택 언어의 번역 결과를
받기 위해 필요합니다.

## 원격 코드

원격 코드를 실행하지 않습니다. 실행 코드는 확장프로그램 패키지에 포함되며, 원격
서버는 번역 API 응답만 반환합니다.

## 개인정보 공개 항목 작성 참고

- `개인 식별 정보(Personal identifiers)` 또는 이에 해당하는 항목: 사용자가 직접 선택한
  성별 정보가 관계별 호칭 번역에 사용되므로 수집/처리에 체크
- `개인 통신(Personal communications)` 또는 이에 해당하는 항목: 수집/처리에 체크
- `웹사이트 콘텐츠(Website content)`: 받은 메시지 번역 기능 때문에 수집/처리에 체크
- `위치(Location)`: Cloud Run 기본 요청 로그에 IP 주소가 포함될 수 있으므로 체크
- 사용 목적: 핵심 기능 제공
- 판매, 광고, 신용 평가, 무관한 목적 사용: 모두 해당 없음
- 개인정보처리방침 URL:
  `https://anchor-work.github.io/zalo-auto-translator/privacy/`

실제 대시보드 질문 문구가 다르면 정보를 적게 보이게 하는 선택이 아니라, “사용자가
입력한 메시지가 번역 서버와 Gemini로 전송된다”는 사실이 정확히 드러나는 항목을
선택합니다.

## 심사자 테스트 안내

1. `https://chat.zalo.me/`에서 Zalo 계정으로 로그인합니다.
2. 대화방을 열고 Zalo 메시지 입력창을 한 번 클릭합니다.
3. 우측 하단 번역 패널의 한국어 입력란에 문장을 입력합니다.
4. Enter를 한 번 눌러 번역 미리보기를 확인합니다.
5. Enter를 다시 누르거나 `Zalo로 전송` 버튼을 눌러 현재 대화에 전송합니다.
6. Shift+Enter는 줄바꿈이며 Esc는 번역 결과를 취소합니다.

## 스크린샷 체크리스트

실제 Zalo 계정·대화 상대·전화번호·프로필 사진은 모자이크 처리합니다. 기능을 정확히
보여 주는 실제 화면을 사용하고 합성 화면은 사용하지 않습니다.

1. Zalo Web 우측 하단에 번역 패널이 표시된 전체 화면
2. 한국어 원문과 베트남어 번역 미리보기가 함께 보이는 화면
3. 가능하면 개인정보를 가린 전송 완료 화면
